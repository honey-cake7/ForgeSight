# Documentation archive

These snapshots preserve training methods and development evidence. They are
not required for reviewer installation; use the current [setup guide](../SETUP.md).
Older paths, blockers and stage labels describe their recorded checkpoint.

Historical snapshots moved on 25 November 2026. These preserve the complete
original engineering records; archive banners and Markdown relative links were
updated for their new locations. Read current instructions in the
[README](../../README.md), [setup](../SETUP.md), [user guide](../USER_GUIDE.md),
[technical report](../TECHNICAL_REPORT.md) and [status](../STATUS.md).

The [source map](source-map.json) records original paths, Git blobs and hashes.
Historical NOT_RUN/BLOCKED/current-stage statements describe their checkpoint,
not the current application. Model/data manifests and licensed local artifacts
were not moved or rewritten. Original snapshots come from commit `8fef9231e5a7739df344c5eb7ab54528d5ccb92f`.
